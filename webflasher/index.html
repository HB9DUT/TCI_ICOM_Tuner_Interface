TCI to ICOM Tuner Interface

Firmware installer · version …

Install

Connect the ESP32 via USB and click the button. Select the serial port in the dialog that opens.

Your browser does not support Web Serial. Please use Chrome or Edge on a desktop computer. Web Serial requires a secure connection (https).

When updating, you can choose whether to erase the device. Without erasing, the settings are kept.

Requirements

  • ESP32 board with the classic ESP32 chip and at least 4 MB flash, e.g. ESP32-DevKitC. ESP32-S2, -S3, -C3 and -C6 are not supported.
  • Chrome or Edge on a desktop computer.
  • USB driver for the board's serial chip, if the port does not appear: CP210x or CH340.
  • If the connection fails, hold the BOOT button on the board while connecting.

After installation

  1. Connect to the Wi-Fi access point TCI-Tuner-XXXX, password tci-tuner.
  2. The configuration page opens by itself; otherwise open http://192.168.4.1/.
  3. Enter your Wi-Fi and the TCI server of ExpertSDR3, then save.
  4. The interface is then reachable at http://tci-tuner.local/.

Later updates can also be installed in the web interface of the device: download firmware.bin from the latest release.
